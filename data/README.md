# data/

Most of this folder is **excluded from version control**. It holds roughly
0.5 GB, and `predicted_capacity_pixels.csv` (107 MB) is larger than GitHub's
100 MB per-file limit, so a push that included it would be rejected.

Four small files **are** included, so that the validation and most of the
figures can be reproduced from a clone without regenerating everything:

- `sample400_full.csv`
- `sample400_blind.csv`
- `phase3_trajectories.csv`
- `pixels_with_covariates.csv`

Everything else is regenerated by the notebooks from public sources. Run
`notebooks/01` through `notebooks/05` in order and this folder rebuilds
itself.

## External sources

- **Landsat Collection 2 surface reflectance**, USGS. Sensor harmonisation
  follows Roy et al. (2016).
- **Global Mangrove Watch v3** mangrove extent (Bunting et al. 2022).
- **SILO Data Drill**, Queensland Government — gridded daily climate. The API
  takes an email address as the username, read from the `SILO_EMAIL`
  environment variable, with a fixed public password. No private credential
  is stored in this repository.
- **Digital Earth Australia Water Observations** (Mueller et al. 2016) —
  distance to tidal channel.

## A caution

Numbers quoted in the manuscript come from runs against these files on the
author's machine. A file regenerated on another machine should reproduce
them, but if any figure script's printed check disagrees with the manuscript,
trust neither until the discrepancy is explained. Each figure script prints
the values it produces for exactly this reason.
